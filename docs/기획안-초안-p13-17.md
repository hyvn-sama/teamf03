### ② 구현한 핵심 기능 체크  `[10/7 최종 점검 후 체크]`
- [ ] 핵심 기능이 실제로 작동한다 (안내장 생성 → 링크 → 참석 응답 → 참석 현황 반영)
- [ ] 버튼·입력 등 상호작용이 동작한다
- [ ] 입력한 데이터가 저장·유지된다 (새로고침·다른 기기에서도)
- [ ] 모바일·PC 화면에서 깨지지 않는다
- [ ] 배포 링크로 바로 접속된다

### ③ 막힌 지점 & 해결 과정 (Before → After → 검증)

**사례 1 (실제 발생, 10/1 개발 환경 세팅)**
- **Before:** 첫 코드를 GitHub에 올리려는데 권한 오류. 확인해 보니 PC에 로그인된 GitHub 계정(`hyun-sama`)과 저장소 주인 계정(`hyvn-sama`)이 **철자 한 글자 차이로 다른 계정**이었음.
- **After:** AI에게 권한 상태를 확인시키고, 저장소 주인 계정으로 다시 로그인한 뒤 이 저장소에서만 해당 계정으로 커밋·푸시되도록 설정.
- **검증:** 저장소 권한 조회 결과 push 권한 `true`, GitHub에 올라간 커밋과 내 PC의 커밋이 일치하는 것 확인.

**사례 2 `[구현 중 실제로 막힌 지점으로 교체]`**
- 후보: 참석자 응답이 주최자 화면에 안 보이던 문제 / 동시 응답 시 덮어쓰기 / 휴대폰에서 날짜 입력 칸이 깨지던 문제
- 형식: 막힌 화면 캡처 + 그때 프롬프트 → 고친 프롬프트 → 3명 동시 접속으로 다시 확인한 결과

### ④ 배포 URL · 심사위원 실행 가이드
- **배포 링크:** `[https://______.vercel.app]`
- **테스트 계정:** 휴대폰 번호 `[ ]` / 비밀번호 `[ ]` (시연용 모임을 미리 만들어 둔 심사용 계정). 참석 응답만 할 때는 로그인 없이 링크로 바로 가능
- **핵심 기능 재현 3단계:**
  ① 첫 화면 **모임장 만들기** → 정보 입력 후 **안내장 만들기**
  ② 생성된 링크를 **다른 기기(휴대폰)**에서 열어 **참석** 응답
  ③ 처음 기기에서 **내 알림장 → 참석 현황**에서 응답 반영 확인 → **정산 등록** → 휴대폰에서 **입금했어요**
- **알려진 제약:** 카카오톡 자동 알림은 불가 → '카톡으로 다시 공유' 버튼으로 링크를 재전송. 로그인은 전화번호 + 비밀번호 방식이라 문자 본인 인증·비밀번호 찾기는 없음 (확장 과제).

### ② 화면 1 — 무엇을 하는 화면인가
**화면 이름:** 안내장 만들기
주최자가 모임명·날짜·시간·장소·참가비·준비물·유의사항을 입력하면 **오른쪽 미리보기에 즉시 반영**됩니다. 필수 항목(모임명·날짜·시작 시간·장소)만 채워도 안내장이 완성되고, 버튼 한 번으로 카톡에 공유할 링크가 생깁니다.

### ③ 화면 2 — 결과 · 데이터가 보이는 순간
**화면 이름:** 초대장 보기 (참석자 화면)
흩어져 있던 정보가 **링크 하나에 정리된 순간**입니다. D-Day가 자동으로 계산되고, 장소·시간이 바뀌면 **바뀐 항목이 주황색으로 표시**됩니다. 참석자는 여기서 바로 참석 여부를 누르고 캘린더에 저장합니다.
