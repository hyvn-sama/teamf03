# 로그인(전화번호 + 비밀번호) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 전화번호 + 비밀번호 로그인을 추가해 내가 만든·응답한 모임이 어느 기기에서든 "내 알림장"에 보이게 한다.

**Architecture:** 서버(`api/events.js`)에 signup/login/logout/whoami/mine/me/claim 액션을 추가하고, 세션 토큰은 Redis `session:{token}`(30일)에 둔다. 주최자·참가자 권한은 기존 토큰 **또는** 세션 사용자로 확인한다. 입력 검증은 공용 `js/auth.js`, 비밀번호 해시는 서버 전용 `api/_auth.js`(scrypt). 클라이언트는 `js/api.js`가 모든 요청에 세션을 자동으로 붙이고, 체험 모드(로컬)도 같은 규칙을 흉내 낸다.

**Tech Stack:** 바닐라 JS(ES modules), Vercel Node 함수, Upstash Redis REST, `node:test`, `node:crypto` scrypt.

**Spec:** `docs/superpowers/specs/2026-10-04-login-design.md`

## Global Constraints
- 브랜치 금지, `main`에만 커밋. **푸시는 사용자가 말할 때만.**
- 프레임워크·npm 의존성 추가 금지 (바닐라 JS, `node:` 내장 모듈만).
- 비밀번호 4~30자, scrypt + 사용자별 salt. 원문·해시를 응답에 포함하지 않음.
- 세션 30일(`EX 2592000`). 로그인 실패 같은 번호 10회 → 15분(900초) 차단.
- 전화번호는 숫자만 `01012345678`. 공개 응답(`GET ?id=`, bundle)에 `ownerPhone`/`userPhone` 절대 포함 금지.
- 안내장 만들기·내 알림장은 로그인 필수, 참석 응답은 로그인 선택.
- 사용자에게 보이는 문구는 한국어 해요체.

## Review Focus
1. **같은 사람이 로그인 전·후 두 번 응답** → 로그인 응답은 기존 계정 응답을 고쳐야 하고 새 참가자를 만들면 안 됨 (Task 3 테스트 `rsvp 중복 방지`).
2. **로그인한 주최자가 다른 기기(토큰 없음)에서 수정·정산** → 세션만으로 허용, 다른 사용자 세션은 403 (Task 3 테스트).
3. **만료·로그아웃된 세션으로 요청** → 401이고 클라이언트는 세션을 지우고 로그인 화면으로 (Task 2 테스트 `logout 후 whoami 401`, Task 5 처리).
4. **전화번호 형식 다양함**(`010-1234-5678`, 공백, `+82`) → 같은 사람으로 정규화 (Task 1 테스트).
5. **시연용 샘플 불러오기**가 로그인 세션을 참가자 19명에게 붙여 한 명으로 합쳐지면 안 됨 → 샘플 응답은 익명으로 (Task 6, `api.rsvp(..., { anonymous: true })`).

```js
// 로그인 입력 검증 (브라우저·서버 공용). 비밀번호 해시는 서버 전용 api/_auth.js
import { InputError } from './ops.js';

export function normalizePhone(raw) {
  let d = String(raw ?? '').replace(/\D/g, '');
  if (d.startsWith('82')) d = `0${d.slice(2)}`;
  if (!/^01[016789]\d{7,8}$/.test(d)) throw new InputError('휴대폰 번호를 확인해주세요. (예: 010-1234-5678)');
  return d;
}

export function formatPhone(d) {
  return d.length === 11 ? `${d.slice(0, 3)}-${d.slice(3, 7)}-${d.slice(7)}` : `${d.slice(0, 3)}-${d.slice(3, 6)}-${d.slice(6)}`;
}

export function cleanPassword(raw) {
  const p = String(raw ?? '');
  if (p.length < 4 || p.length > 30) throw new InputError('비밀번호는 4~30자로 입력해주세요.');
  return p;
}

export function cleanSignup(raw) {
  const name = String(raw.name ?? '').trim();
  if (!name || name.length > 20) throw new InputError('이름을 1~20자로 입력해주세요.');
  return { phone: normalizePhone(raw.phone), name, password: cleanPassword(raw.password) };
}
```

```js
// 비밀번호 해시 (scrypt + 사용자별 salt). 서버 전용
import { scrypt, randomBytes, timingSafeEqual } from 'node:crypto';

const KEYLEN = 32;
const derive = (pw, salt) => new Promise((resolve, reject) => {
  scrypt(pw, salt, KEYLEN, (err, key) => (err ? reject(err) : resolve(key)));
});

export async function hashPassword(pw, salt = randomBytes(16).toString('hex')) {
  return { hash: (await derive(pw, salt)).toString('hex'), salt };
}

export async function verifyPassword(pw, user) {
  const key = await derive(pw, user.salt);
  const stored = Buffer.from(user.passHash, 'hex');
  return stored.length === key.length && timingSafeEqual(stored, key);
}
```

```js
export async function getUserEvents(phone) {
  const flat = (await cmd('HGETALL', `user:${phone}:events`)) || [];
  const out = {};
  for (let i = 0; i < flat.length; i += 2) out[flat[i]] = JSON.parse(flat[i + 1]);
  return out;
}
export async function addUserEvent(phone, eventId, info) {
  const key = `user:${phone}:events`;
  const prevRaw = await cmd('HGET', key, eventId);
  const prev = prevRaw ? JSON.parse(prevRaw) : {};
  const next = { ...prev, ...info, role: prev.role === 'host' || info.role === 'host' ? 'host' : 'guest', at: prev.at || new Date().toISOString() };
  await cmd('HSET', key, eventId, JSON.stringify(next));
  await cmd('EXPIRE', key, USER_TTL);
  return next;
}
```

```js
const MAX_FAILS = 10;
const publicUser = (u) => ({ phone: u.phone, name: u.name });

async function sessionUser(session) {
  if (!session || typeof session !== 'string' || session.length > 64) return null;
  const phone = await db.getSession(session);
  if (!phone) return null;
  const u = await db.getUser(phone);
  return u ? publicUser(u) : null;
}
function needUser(user) {
  if (!user) throw new HttpError(401, '로그인이 필요해요.');
  return user;
}
async function startSession(u) {
  const session = newId(32);
  await db.setSession(session, u.phone);
  return { session, user: publicUser(u) };
}
```
